# Country Search

Учебный проект RS School: поиск стран с отменой устаревших запросов.

## Разработка

Требуется Node.js 24 LTS и npm.

```sh
npm ci
npm run lint
npm run format:check
npm run typecheck
npm test
npm run build
```

Сборка создаётся в `dist`. Откройте корень проекта через локальный HTTP-сервер.
Вся логика и интерфейс будут добавляться после тестов отдельными коммитами.
